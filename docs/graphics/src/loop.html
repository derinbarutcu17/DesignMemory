The agent loop with Design Memory

Context before code. Deterministic gate after code. Memory across sessions.
01

Ask first

dm_get_context

Tokens, contracts, and prior decisions for the files about to change.

02

Write

The agent edits UI code inside the returned vocabulary.

03

Gate

dm_audit_diff

Net-new findings with line/col and wouldBlock.

04

Repair

dm_suggest_token

Exact or nearest approved token for each flagged value.

05

Remember

dm_record_decision

Only for human-approved deviations, with a reason.

06

Re-run

Audit until clean; decisions keep settled findings quiet.

# Design Memory Showcase Design System

## Overview

A minimal React/Tailwind design system used to demonstrate Design Memory drift detection. The reference contract below drives every audit in this showcase.

## Tokens

- Primary: `#2563eb`
- Surface: `#ffffff`
- Text: `#0f172a`
- Spacing unit: `4px`

## Button

Primary action button for forms and dialogs.

Must use: `bg-primary`, `px-4`, `py-2`
Disallowed: `style={{`
States: hover
Variants: primary, secondary
